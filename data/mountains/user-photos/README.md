# 用户自备封面图 · 拾取目录（最高优先级）

你自己找到/拍到觉得合适的封面图放这里，**优先级最高、覆盖自动候选**。管线处理每座山时会先看这个目录，有就用你的、没有才走自动检索。

## 命名约定（务必照此，方便按山峰名精确拾取）

**方式 A（推荐·支持多图轮播）**：每座山一个子文件夹，文件夹名 = 山峰中文名，里面放 1-N 张图。
```
user-photos/
  泰山玉皇顶/           1.jpg  2.jpg  3.jpg      # 多张 = 轮播，文件名随意，按字母序
  慕士塔格峰/           a.jpg
  凤凰山（辽宁）/        x.jpg                    # ⚠️同名异山必须加省份消歧
  凤凰山（广东）/        y.jpg
```

**方式 B（单图·省事）**：直接平铺文件，文件名 = 山峰中文名。
```
user-photos/
  达瓦更扎.jpg
  齐云山（江西）.jpg
```

## 规则
- **同名异山**（凤凰山/齐云山/云顶山/灵山/大明山/天堂寨/黄岗山/雾灵山）**必须带省份**：`名（省）`，否则我无法区分。
- 山峰名用**我给你的清单里的准确写法**（每批的勾选页/清单里都有）。
- 图片格式 jpg/png/webp 均可；建议横图、清晰、能当封面。
- 放好后跟我说一声「user-photos 更新了」，我扫描拾取、并入该座候选（你的图排最前）。
